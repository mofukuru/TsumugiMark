# TsumugiMark

TsumugiMark は [Obsidian](https://obsidian.md) 向けの縦書き編集プラグインです。任意の Markdown ノートを専用の縦書きペインで開くことができ、小説・脚本・縦書き文書の執筆に最適です。

> **注意：本プラグインはベータ版です。一部の機能が安定していない場合があります。重要なファイルで使用する前に、必ずバックアップを取るか、コピーで動作確認を行ってください。**

## 主な機能

### 基本機能

- **縦書き表示**: アクティブな Markdown ファイルを、CSS `writing-mode: vertical-rl`（または `vertical-lr`）を使った別ペインで表示します。
- **ライブプレビュー**: 標準 Markdown エディタで保存した変更が、縦書きペインにリアルタイムで反映されます。
- **縦書きのまま編集**: 縦書きペインで直接入力・編集できます。編集内容は元の Markdown ファイルに自動保存されます。
- **見出しの直接入力**: 段落の先頭で `#`（または `##`〜`######`）を入力してスペースを押すと、対応するレベルの見出しに即時変換されます。
- **ルビ記法**: `｜漢字《かんじ》` または `漢字《かんじ》`（自動検出）形式のルビをサポートします。
- **文字数カウント**: ステータスバーに文書全体の文字数を表示します。テキストを選択すると選択範囲の文字数も表示されます。
- **全ノートを縦書きで自動表示**: ツールバーボタンを押さずに、Markdown ノートを開くたびに自動で縦書きエディタに切り替えるオプションです。
- **カスタマイズ**: フォント、フォントサイズ、行間、文字間隔、縦書きの方向、列の配置、自動字下げ、文字数カウント方法などを設定画面から調整できます。

### 高度な機能

- **縦書きの方向選択**: 設定から「右から左（伝統的な縦書き）」または「左から右」を選択できます。
- **列の配置**: テキスト列を画面のどの位置に表示するか（左・中央・右）を設定できます。読みやすさや編集のしやすさに合わせて調整してください。
- **自動保存**: 入力を止めてから 2 秒後に自動保存されます。ペインを閉じる際にも即座に保存されます。
- **Markdown ラウンドトリップ**: 縦書きエディタは表示時に Markdown → HTML、保存時に HTML → Markdown に変換します。見出し・太字・斜体・ルビ・強制改行・空行が保持されます。
- **外部編集の検出**: 縦書きエディタを開いたまま標準エディタ側でファイルを編集・保存した場合、縦書きペインが自動的に再読み込みされます。

## 使い方

### 縦書きエディタを開く

**方法 1 — ツールバーボタン**
1. Markdown ファイルを開きます。
2. エディタペイン右上のアクションバーに表示される**ノートアイコン**をクリックします。
3. 画面が分割され、右側に縦書きエディタが表示されます。

**方法 2 — コマンドパレット**
1. `Cmd/Ctrl + P` でコマンドパレットを開きます。
2. `TsumugiMark: 縦書きエディタを開く` を実行します。

### 縦書きエディタで見出しを直接入力する

Markdown ソースビューに戻ることなく見出しを追加できます。

1. 空の段落にカーソルを置きます（必要であれば `Enter` で新しい段落を作成してください）。
2. H1 なら `#`、H2 なら `##`、H3 なら `###`（〜 H6 の `######` まで）を入力します。
3. **スペース**を押すと、その段落が対応する見出し要素に即時変換されます。
4. 見出しのテキストを入力します。次の自動保存のタイミングで、Markdown ファイルに `# タイトル`、`## タイトル` などの形式で保存されます。

### 全ノートを縦書きで自動表示する

オンにすると、Markdown ノートを開くたびに自動的に縦書きエディタで表示されます。

1. **設定 → TsumugiMark** を開きます。
2. **「全ノートを縦書きで開く」** をオンにします。
3. 任意の Markdown ノートを開くと、自動的に縦書きエディタに切り替わります。

> 同じファイルの縦書きペインがすでに開いている場合は、そのペインがフォーカスされます（新しいペインは作成されません）。

### 縦書きの方向を変更する

1. **設定 → TsumugiMark** を開きます。
2. **「縦書きの方向」** を選択します：
   - **右から左（伝統的な縦書き）** — デフォルト。列が右から左へ流れる伝統的な日本語縦書きです。
   - **左から右** — 列が左から右へ流れます。

### 列の配置を調整する

1. **設定 → TsumugiMark** を開きます。
2. **「列の配置」** を **左** / **中央** / **右** から選択します。
   - **右**（デフォルト）は右から左の縦書きで最初の列が画面右端に置かれる自然な配置です。
   - **中央** はテキストを画面中央に表示したい場合に便利です。
   - **左** は左から右の縦書きに自然な配置です。

## 設定項目

**設定 → TsumugiMark** からすべての設定を変更できます。

| 設定 | 説明 |
|---|---|
| **文字数カウント方法** | 空白・改行を含めてカウントするか、除外してカウントするかを選択します。 |
| **フォントファミリー** | 縦書きエディタで使用するフォント（例：`"游明朝", serif`）。 |
| **フォントサイズ** | フォントサイズ（例：`18px`、`1.2em`）。 |
| **行間** | 列と列の間隔（例：`1.8`、`2`）。 |
| **文字間隔** | 文字間のスペース（例：`0px`、`0.1em`）。 |
| **一行の文字数** | 1 列あたりの目標文字数。設定すると **一行の最大幅** が自動計算されます。 |
| **縦書きの方向** | `右から左（伝統的な縦書き）` または `左から右` を選択します。 |
| **列の配置** | 画面上のテキスト列の水平位置：`左` / `中央` / `右`。 |
| **全ノートを縦書きで開く** | Markdown ノートを開くたびに自動で縦書きエディタに切り替えます。 |
| **段落の自動字下げを有効化** | 各段落の先頭を 1em 字下げします（小説スタイル）。 |
| **一行の最大幅** | 列の最大高さを CSS 単位で指定（例：`500px`、`auto`）。通常は **一行の文字数** から自動設定されます。 |

## 注意事項

### ベータ版について
本プラグインはベータ版です。エッジケースでレイアウトが崩れる場合があります。重要なデータには必ずバックアップを取った上でご使用ください。

### 見出し変換のルール
`#` + スペースによる見出し変換は、**段落全体が `#` 文字のみで構成されている場合**にのみ動作します。例：
- `###` → スペース → H3 に変換 ✓
- `## こんにちは` の末尾にスペース → 変換されない（すでに本文がある）✓

### 縦書きの方向と列の配置の組み合わせ
右から左（`vertical-rl`）の場合、**右** の配置が最初の列を画面右端に置く自然な読み方の位置です。`vertical-rl` で **左** 配置を選ぶと最初の列が画面左端になり、読み方向と逆になります。

### Markdown 変換の対応範囲
Markdown ↔ HTML の変換は、見出し・太字・斜体・ルビ・改行などの一般的な記法に対応しています。表・タスクリスト・生の HTML などの複雑な記法は、正しくラウンドトリップされない場合があります。

## バージョン履歴

### 1.0.2
- **縦書きエディタで見出しを直接入力** — 段落先頭で `#`（または `##`〜`######`）を入力しスペースを押すと見出しに変換。Markdown ファイルにも `# タイトル` 形式で正しく保存されます
- **全ノートを縦書きで自動表示** — 設定のトグルで Markdown ノートを開くたびに縦書きエディタへ自動切替
- **縦書きの方向設定** — 右から左（デフォルト）または左から右を選択可能
- **列の配置設定** — テキスト列の水平位置を左・中央・右から選択可能
- 列の配置を「右」に設定するとスクロールできなくなる問題を修正
- 見出しなどのブロック要素が保存時に Markdown に正しく変換されない問題を修正（`HTMLElement` を TurndownService に直接渡していたため `<h1>` 等が無視されていた。`outerHTML` に変更して解決）
- 全ノート自動表示時にスクロールできなかった問題を修正：専用のスクロールコンテナを挟むことで Obsidian の `.view-content` スタイルとの干渉を排除
- 全ノート自動表示のトリガーを `file-open` から `active-leaf-change` に変更し、確実に動作するよう修正

### 1.0.1
- ルビ記法のパース改善 — `start()` 検出関数を修正し、踊り字（々・〆など）にも対応
- `EditorManager` をリファクタリング — カーソル位置制御と段落分割をより堅牢に
- `FileManager` を改善 — 空行のラウンドトリップと外部編集の検出をより確実に
- 見出しと空行の CSS を改善し、縦書きレイアウトをよりきれいに表示
- その他エディタおよび保存サイクルに関するバグを修正

### 1.0.0
- 初回リリース
- `writing-mode: vertical-rl` による縦書き表示ビュー
- 標準 Markdown エディタでの変更のライブプレビュー
- 縦書きペインでの直接編集と自動保存
- ルビ記法（`｜漢字《かんじ》` および自動検出）のサポート
- ステータスバーへの文字数表示（選択範囲の文字数も対応）
- フォント・サイズ・行間・文字間隔・自動字下げのカスタマイズ
- 一行の文字数設定と最大幅の自動計算
